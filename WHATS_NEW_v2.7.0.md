## What's new in v2.7.0

- **Double-click to save.** Turn on "Double-click the selection to save it instantly" in Settings, then double-click inside a selection to save it straight to your save folder, with no dialog. If you haven't picked a folder, it uses `Pictures\SnipFor`. Handy when you need to save several screenshots in a row. It's off by default and doesn't interfere with drawing tools or text editing.
- **Smart capture.** Hover over a window, panel, or other element on screen and the selection frame snaps to it, so you capture exactly what you mean without dragging precisely. Detection uses Windows UI Automation plus visual analysis, and works with modern flat-style interfaces too.
- **Freeze protection.** A small background watchdog notices if SnipFor stops responding and restarts it automatically.
- **Easier error reporting.** The crash dialog now has a "Copy error" button, and Settings includes an error log viewer, so a problem can be described precisely.
- Saved screenshots now include milliseconds in the file name, so several captures in the same second can no longer overwrite each other.

## v2.7.0'da yenilikler (Türkçe)

- **Çift tıkla kaydet.** Ayarlar'da "Seçime çift tıklayınca anında kaydet" seçeneğini açın; seçimin içine çift tıklayınca görüntü diyalog çıkmadan doğrudan kayıt klasörünüze kaydedilir. Klasör seçmediyseniz `Resimler\SnipFor` kullanılır. Peş peşe birkaç görüntü kaydetmeniz gerektiğinde kullanışlıdır. Varsayılan olarak kapalıdır, çizim araçlarını ve metin düzenlemeyi engellemez.
- **Akıllı yakalama.** Ekrandaki bir pencerenin, panelin ya da öğenin üzerine geldiğinizde seçim çerçevesi ona oturur; tam istediğiniz bölgeyi hassas sürükleme yapmadan yakalarsınız. Algılama Windows UI Automation ve görsel analizle yapılır, modern düz tasarımlı arayüzlerde de çalışır.
- **Donma koruması.** Arka planda çalışan küçük bir bekçi süreç SnipFor'un yanıt vermediğini fark ederse programı otomatik olarak yeniden başlatır.
- **Daha kolay hata bildirimi.** Hata penceresinde "Hatayı kopyala" düğmesi ve Ayarlar'da hata günlüğü görüntüleyici var; sorunu doğru biçimde aktarabilirsiniz.
- Kaydedilen görüntülerin dosya adı artık milisaniye içerir; aynı saniyedeki birkaç yakalama birbirinin üzerine yazılmaz.
